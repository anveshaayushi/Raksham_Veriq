# How we measured

## Plain words
Plain words: every number has a command that re-creates it (`make reproduce`). Synthetic chats were generated by us
from a fixed seed, so they test our own design; that is why we added public data (ASVspoof, SMS Spam) and a blind set
written by teammates who did not see the rules. 17 deliberately planted bugs were all caught by the tests.

| | |
|---|---|
| Code | `bench/`, `eval/`, `scripts/reproduce.py`, `scripts/mutation_check.py` |
| Goes in | datasets and kits |
| Comes out | RESULTS.md rows with date, command and data |
| Can do | repeat the same numbers on another machine |
| Cannot say | real-world accuracy on real victims' chats |
| Tests / numbers | `tests/completeness/` |
| Known limit | Small sets: read the 95% intervals. |
