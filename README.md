# VERIQ: check who you are paying, before you pay

**Team The Outliers · RAKSHAM Grand Finale, IIT Delhi (24–25 Oct 2026)**

Investment and "SEBI advisor" scams in India get victims to pay a UPI ID or bank account that belongs to someone
else. The chat says *"Navyug Wealth Research"*; the money goes to *"VIKRAM MOBILE POINT"*. VERIQ reads the chat
before you pay, lists every place you were asked to pay, compares the name **your own bank app** shows with the firm
the chat claims, and gives one answer per payee: why it fired, and what to do next.

It runs on your laptop, blocks nothing, contacts no one (no bank, UPI, SEBI or police system), and saves nothing.

## Run it (Windows, from this folder)
```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File app\run_app.ps1 -SkipTests      # opens http://localhost:8501
```
macOS/Linux: `bash app/run_app.sh`. Check an install: `python scripts/smoke.py`.

## Try it in 2 minutes
1. **Check a chat:** consent → paste or upload a WhatsApp chat (or **Try a synthetic demo** → A) → type the firm the
   sender claimed → type the name your bank app shows → the answer, with why it fired and four actions
   (don't pay, check the name, ask a person to review, download a 1930 report pack).
2. **Judges' test kit:** left menu **For judges and reviewers → Kit runner**, upload a .zip of chats, voice notes or QR
   images (example: `demo/veriq_demo_kit.zip`). Same code on the command line:
   `python -m eval --input <folder> --out preds.csv --report report.md`.
3. **Measured results:** toggle **How accurate is VERIQ?** in the same menu, or read `RESULTS.md`.

## How it works
| Step | Code |
|---|---|
| Read the WhatsApp export (dates, senders, voice notes, images) | `parsing/` |
| Find every payee (UPI IDs, including hidden ones like "x dot y at ybl"; account numbers; QR codes), IFSC, links, SEBI numbers and pressure tactics | `extract/`, `parsing/qr.py` |
| Compare the claimed firm with the bank-app name: match / different business / look-alike / can't tell | `match/` |
| Decide per payee from evidence classes (your bank-app name outranks anything the sender supplies) | `rules/`, `core/` |
| Cross-victim registry: links a payee after 2 independent reports, stores only keyed hashes | `registry/` |
| Voice-note check: pretrained AASIST, a review cue only, never clears a payee | `voice/` |
| Reports: filing sheet for 1930 / cybercrime.gov.in, shareable summary with accounts cut to 4 digits | `report/` |
| App: 6 steps, per-payee cards, review and overturn, results page, Kit runner | `app/` |

## What is new compared with what exists today
| Today | VERIQ adds |
|---|---|
| UPI apps show the account-holder name before you pay, but leave the comparison to the user | compares that name with the firm the chat claimed, and says in plain words when they don't belong together |
| SEBI's `@valid` UPI handles and intermediary list exist, but the user has to know to check them | reads the SEBI number quoted in the chat and checks it against a dated list; explains `@valid` when it appears |
| Spam filters look at one message for keywords | reads the whole conversation: every payee, payee switches, pressure tactics, links |
| Victims report after the loss | a cross-victim registry links a payee after two independent reports |
| A warning with no way out for a genuine user | every alert says why it fired; a genuine user asks for review and a person can overturn it, with an audit trail |

## Where we are going next
- **Stronger name evidence:** the bank's own name lookup at the payment screen (with a bank or UPI partner) instead of
  the user typing it, and the real SEBI list as a dated file instead of our synthetic one.
- **Accounts opened in the firm's exact name:** the one case a name check cannot catch; next is account-age and report
  signals that only a bank can see.
- **Pressure without keywords:** a small classifier trained on consented, labelled Indian scam chats.
- **Voice:** train and test on many TTS and voice-clone engines and on Indian languages.
- **Speech-to-text:** measure it on Hinglish recordings and wire it into the app.
- **Real-world data:** a pilot with a bank fraud desk or a cyber cell for the first real error rates.
  `EVASION_LAB.md` lists each known gap with the change we would make.

## Data and AI use
All chats are synthetic or AI-generated and fictional; their generation code is in this repo (`bench/generate.py`,
`data/synthetic/`, `generation/`, `scripts/make_demo_kit.py`). Voice data is public (ASVspoof 2019 LA, Free Spoken
Digit Dataset) or synthetic (Kokoro TTS, `bench/voice/make_set.py`). Claude (Anthropic) was used to write code and
documents under the team's direction.
