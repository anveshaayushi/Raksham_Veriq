# SUBMISSION: VERIQ · Team The Outliers · RAKSHAM Grand Finale, IIT Delhi

**What it is.** VERIQ checks a suspicious money chat (WhatsApp export, voice notes, QR screenshots) **before the user
pays**: who the chat says you are paying, and who would actually receive the money. It lists every payment
destination, compares the name the user's own bank app shows with the claimed firm, checks the quoted SEBI number
against a dated list, looks for pressure tactics, asks whether other victims reported the same payee, and treats a
voice note only as a review cue. One answer per payee from fixed rules, with evidence and a next step (1930 if money
was sent). It blocks nothing, files nothing and contacts no one.

No internet at the venue: DEPLOY.md section 2 (offline bundle). Server: `docker compose up` (DEPLOY.md section 4).

## Reproduce every result
`powershell -ExecutionPolicy Bypass -File reproduce.ps1` or `make reproduce` (REPRODUCE.md): regenerates our synthetic
data byte for byte from seeded generators, runs all tests with coverage and in random order, re-runs the benchmarks and
compares each number with the committed one. Full acceptance list: `python scripts/acceptance.py` →
`results/ACCEPTANCE.md`. Judges' own test kit: `veriq-eval --input <kit> --out preds.csv --report report.md`
(or the app's Kit tab).

## Known limits and gaps (say these before anyone asks)
- Chat accuracy numbers are on chats we generated (partly circular); the blind teammate set is small.
- Voice: no threshold transferred across datasets; the app uses pretrained AASIST with an ASVspoof-dev threshold only as a weak review cue (a flag asks for review; nothing is cleared by voice). Pretrained AASIST on held-out
  ASVspoof LA eval (in-distribution): AUC 0.77, misses 56% of synthetic clips at a dev threshold.
- Name matcher: 3/42 same-firm names in our pair set still called a discrepancy (abbreviations, joined words).
- Evasion: a mule account in the firm's exact name, pressure without keywords, links sent outside the chat.
- Not built: speech-to-text, OCR of screenshots without QR, voice check on the team's own voices and clones.
- Docker files written but not built by us (no Docker Hub access in the build sandbox); phone demo not verified.
